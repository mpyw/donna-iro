# donna-iro

「どんな色がすき？」の呼びかけに子どもが色名を叫ぶと、その色の続きが流れる音声インタラクティブ遊び。
Raspberry Pi + マイク + スピーカー（またはテレビ）で動かす。

対象は2歳児。

## しくみ

```
質問を再生 → 数秒だけ録音 → 色名を判定 → 該当する色の続きを再生
```

カメラもディスプレイも使わない。音声のみで完結させる。

## 設計方針

### 無反応にしない

これが最優先。2歳児は間違った色が流れても大して気にしないが、
声を出したのに何も起きないと一気に興味を失う。

- 何か声が出たら**必ず**続きを流す
- 色が判定できたらその色、できなければランダムに選ぶ
- 「わかんないなあ、もういっかい？」は多用しない

失敗モードを「無反応」ではなく「違う色」に倒す。

### 幼児の声は汎用 ASR が苦手

基本周波数が成人の2〜3倍あり、調音も不明瞭。Whisper 等をそのまま使っても
期待通りには動かない前提で組む。

ただし語彙は色名10語未満に閉じているので、フルの音声認識は不要。

**A. whisper.cpp（まず試す）**
tiny/base の日本語モデルで文字起こし → 色名リストにあいまい一致。
1時間で組めるので、実際の子どもの声で動くかをまず確かめる。

**B. 専用分類器（本命）**
各色20〜30回録音して MFCC + 小さな CNN で分類。汎用性はないが、
特定の子の特定の10単語なら汎用 ASR より精度が出るし軽い。
録音を集める作業自体が親子で遊べる。

### 自分の音でループしない

テレビから流れる質問音声をマイクが拾って誤爆する。
エコーキャンセルには手を出さず、**質問終了直後の数秒だけ聞く**
ウィンドウ制御で回避する。call-and-response の構造にも合っている。

## ハードウェア

- Raspberry Pi 5
- USB マイク（離れた場所から拾うなら ReSpeaker 等のマイクアレイ HAT）
- スピーカー or HDMI でテレビ

## 音源について

**音源はリポジトリに含めない。** 曲は著作物。
家庭内で自分の音源を使って遊ぶ分には問題ないが、コードだけを公開する形にする。

`assets/` に以下を置く想定（gitignore 済み）:

```
assets/
  question.wav      # 「どんないろがすき？」
  red.wav           # あかの続き
  blue.wav
  yellow.wav
  ...
```

## MVP

1. 曲を「質問」と「色ごとの続き」に切り分けて音声ファイル化
2. 質問再生 → 3秒録音 → whisper.cpp → 色名マッチ → 該当ファイル再生
3. マッチしなければランダム再生
